# veyro-privacy

La política de privacidad de Veyro: una sola página en los doce idiomas del juego.

Se publica con GitHub Pages igual que `lynko-privacy`: crear el repositorio
`maikel1991p3/veyro-privacy` en GitHub, subir esta carpeta y activar Pages sobre `main`.
Queda en `https://maikel1991p3.github.io/veyro-privacy/`, que es la dirección que abre
el juego desde Opciones → Privacidad y datos, y la que va en la ficha de Google Play.
